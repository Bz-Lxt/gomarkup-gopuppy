帮我用Go语言实现一个一站式宠物健康档案与全生命周期智能管家（宠物全能助手）

业务背景：专门为养宠家庭设计的全栈管理系统。从宠物的日常饮食、接种疫苗、吃药驱虫，到日常开销、异常症状记录、云端相册一应俱全。

前端页面 (Vue 3 / React + Tailwind)：宠物主页卡片：展示宠物头像、年龄（精确到天）、今天是否已喂食/吃药的快捷勾选。健康时间轴（Timeline）：以精美时间线展示宠物一生的重要节点（如：2024-03 做了绝育，2025-06 打了狂犬疫苗）。记账与体重曲线图：利用 Echarts 动态渲染宠物近一年的体重变化和分类开销（猫粮、医疗、玩具）。

Go 后端核心实现：智能动态提醒引擎：基于 Go 的定时任务，计算下一次驱虫或打疫苗的时间，并在当天通过邮件、企业微信群机器人或 Webhook 推送给主人。多媒介存储隔离：宠物的照片、病历单、体检 PDF 上传，后端按宠物 ID 建立目录，支持本地存储与第三方对象存储（OSS/COS）的动态切换。多角色共同养育（RBAC）：支持"家庭"概念，爸爸和妈妈绑定同一个宠物，爸爸喂食后，妈妈的手机端通过 WebSocket 实时看到"已喂食"状态。

文件数与代码量：约 25+ 个 Go 文件，代码量 5000 - 7500 行。
